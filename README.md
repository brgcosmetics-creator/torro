# VinoTorre

Презентационный сайт винодельни на чистом HTML, CSS и JavaScript: три страницы, локальные ресурсы, без npm, сборки, CDN и серверной части. Файлы восстановлены в текущей среде после отсутствия прежнего checkout.

## Запуск

Откройте `index.html` в обычном браузере. Страницы и относительные ссылки рассчитаны на работу через `file://`. Управляемый Chromium облачной среды может блокировать этот режим своей политикой; это не заменяет проверку в пользовательском браузере.

Для локальной разработки из папки сайта:

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8000`. Остановка сервера — `Ctrl+C`.

## Тексты и контакты

Общие данные редактируются в `assets/js/data.js`, в объекте `window.VINOTORRE_CONFIG`:

- `email`, `phone`, `domain`, `instagram`, `address` — контакты и адрес;
- `media.estate`, `media.landscape`, `media.vineyard`, `media.route` — изображения секций (`src`, `srcset`, `alt`);
- `wines` — вина (`id`, `name`, `grape`, `year`, `artwork`, `images`, `characteristics`);
- `legal.ageNotice`, `legal.information` — место для согласованной обязательной информации.

Неизвестные контакты, домен, характеристики и юридические формулировки оставлены пустыми. Добавляйте только подтвержденные сведения. Основные тексты и метаданные находятся в соответствующих HTML-файлах; сохраняйте один `h1` на странице.

Подтвержденный адрес: Волгоградская область, Владимирская слобода, улица Державная, 41. Навигация открывает поиск адреса в Яндекс Картах и не обещает время поездки. Instagram: `vino_torre`. В коллекции — «Каберне Совиньон» и «Мерло», урожай 2025.

## Изображения

Исходные фотографии бутылок, винодельни и маршрута в текущей среде отсутствовали. Локальные SVG — оригинальные иллюстрации, а не документальные изображения места или продукции. Предоставленная ссылка: https://disk.yandex.ru/d/oHrlT4JK0c-QIg . Повторный запрос публичного API Яндекс Диска в этой среде заблокирован сетевым прокси: CONNECT 403. В черновике настроек запрошены cloud-api.yandex.net, disk.yandex.ru и downloader.disk.yandex.ru. После применения доступа нужно повторить загрузку и проверить фактические адреса скачивания. Не считайте иллюстрации заменой подлинным фотографиям.

Добавляйте в `assets/img` собственные или разрешенные к использованию изображения с короткими именами латиницей. Подготовьте оптимизированные WebP и адаптивные размеры. В `data.js` задайте изображения секций через `media`, а фотографии бутылок — через `wines[].images`, например:

```js
images: [{
  src: 'assets/img/cabernet-1200.webp',
  srcset: 'assets/img/cabernet-600.webp 600w, assets/img/cabernet-1200.webp 1200w',
  alt: 'Подтвержденная фотография бутылки Каберне Совиньон 2025',
  caption: ''
}]
```

Это пример структуры, соответствующие фотографии нужно добавить самостоятельно. Укажите точные `alt` и реальные размеры. Обновите также резервные `src` и `srcset` в HTML, чтобы фотографии отображались без JavaScript. Изображение маршрута добавляется в `media.route`; адресная навигация работает и без него.

## Форма посещения

Без настроенного `email` форма отключена и объясняет причину. При валидном email кнопка открывает почтовый клиент через `mailto:` с заполненным письмом. Сайт сам не отправляет сообщения и не подтверждает запись; посетитель отправляет письмо из своего почтового приложения. Автоматическая отправка потребует отдельного согласованного сервиса или backend.

## Архив и размещение

Готовый архив `vino.zip` находится в папке репозитория. Его можно скачать из файлового интерфейса среды, если интерфейс поддерживает загрузку, или забрать вместе с папкой проекта. В архив включены только 20 файлов сайта, без `.git` и без самого архива. Копия для открытия в файловой панели также находится в `/workspace/vinotorre-part-01.zip`. Архив меньше 2 МБ, поэтому состоит из одной части. Внутренние ссылки чата могут открывать просмотр файла вместо загрузки; наличие кнопки скачивания зависит от интерфейса.

Распакуйте содержимое архива прямо в корень статического хостинга: рядом должны находиться три HTML-файла и папка `assets`. Дополнительная внешняя папка не нужна. HTTPS настраивается средствами хостинга. После получения окончательного домена заполните `domain` и пропишите абсолютные canonical, og:url и og:image непосредственно в HTML для роботов без JavaScript; скрипт также добавляет canonical в DOM при заданном домене. Юридические тексты добавляйте после согласования.

Для сохранения текущих файлов в облачном снимке используйте **«Редактировать среду → Сохранить и опубликовать»**. Локальное создание файлов само по себе не публикует среду.

## Проверки

После правок проверьте переходы, изображения, мобильное меню, клавиатуру, закрытие модального окна по `Escape`, форму с пустым и настроенным email, работу без JavaScript и уменьшение анимации. Рекомендуемые ширины: 360, 390, 430, 768, 1024, 1440 и 1920 px.

В текущей среде выполнено 219 проверок в Chromium 154: все прошли. Проверены три страницы на всех семи ширинах, локальные ссылки и изображения, размеры нажатия 44×44, меню и фокус, галерея, модальные окна и прямые ссылки, форма с пустым и временно заданным email, mailto, noJS и reduced motion. Отдельно проверена гонка быстрого закрытия и открытия другого вина: 20 циклов без ошибок. Ошибок JavaScript, недостающих ресурсов и горизонтальной прокрутки не обнаружено. Начальный CLS в локальных прогонах равен 0; это измерения на localhost без сетевого ограничения, не результаты Lighthouse. Прямой file:// заблокирован административной политикой Chromium и не считается проверенным. Оценки Lighthouse не измерялись.
